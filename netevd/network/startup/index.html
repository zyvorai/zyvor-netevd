Module startup 

Source
Expand description

Startup triggers: synthesise link-added / address-added hook events for what already exists when the daemon starts, so scripts do not miss links that were configured before netevd (networkd-dispatcher’s --run-startup-triggers). Enabled by hooks.startup_triggers.

Functions§

build_startup_events
Build the startup events. links is (name, ifindex); addrs yields the addresses present on a link. Links are ordered by ifindex so the result is deterministic; loopback and excluded links are dropped by selector.
fire_startup_triggers
Query current addresses and push the startup events into the hook service. Returns how many events were queued.
