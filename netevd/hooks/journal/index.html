Module journal 

Source
Expand description

Event journal: a bounded in-memory history of dispatched hook events, a live broadcast for streaming, and an optional size-rotated JSONL file.

Each journal line is a netevd.event.v1 object plus seq, outcome, duration_ms and error, so netevd explain --from-file <journal> can replay it unchanged (extra keys are ignored by the event parser).
