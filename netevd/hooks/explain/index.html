Module explain 

Source
Expand description

netevd explain: show what the daemon would do for a synthetic or recorded event, without running anything.

The report is built from the same functions the executor uses (hook_dir, InterfaceSelector, plan_directory, prepare_env), so it cannot drift from real behaviour.
